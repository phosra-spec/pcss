## Cross-cutting themes (appear in 6+ reports)

1. **Canonicalization is specified three ways.** Spec §10.2.1 says EIP-712-style. `capabilities/notary.md` §10.2.1 says EIP-712 + SHA-256. `examples/typescript/implementer.ts` does lex-sorted JSON + sign-bytes. `sdk-typescript/.../canonicalize.ts` does JCS wrapped in `{domain, payload}`. Four implementations, four byte streams. **The single highest-leverage fix.**
2. **No `enforcement_status` field on rules.** KOSA, COPPA 2.0, NY S9051 cited as if enacted in the registry adopters consume programmatically. Credibility risk.
3. **`extensions: additionalProperties: true` everywhere** is a PII smuggling path AND the workaround for every missing field (registry_version, nonce, prev_receipt_hash, device_attestation). One disciplined fix here unblocks five v1.1 OIs.
4. **`signature.alg` closed enum** means OI-9 PQ migration is a breaking change. Two minutes of pre-emptive schema work, infinite migration value.
5. **No `.github/` substrate at all** despite CONTRIBUTING.md naming three CI checks that don't exist. Single biggest "the docs lie about the substrate" trust break.

## What changes for the reader

**At today's 60 average:** "Interesting, well-organized, but contradicts itself on canonicalization, the conformance suite doesn't run, the reference can't sign bearings, and the rules cite a bill that's not law as if it were." → Files under "watch."

**After items 1–8 (63h, ~78 avg):** "Canonicalization is pinned with test vectors. The conformance suite actually fails my fail-open mock. The reference server `docker run`s and signs receipts. Rules are tagged proposed/in-force." → Recommends adoption pilot.

**After items 1–15 (150h, ~90 avg):** "I'd implement this." Foundation transition closes the remaining 10 points by H3 2027.

## Methodology

Twelve agents launched in parallel on 2026-05-11, each scoring one dimension with hard anchors (100 = "Cloudflare-grade adopt without filing a ticket"; 40 = "draft"). Each agent named the 5 most concrete gaps in their dimension with file paths and the specific fix. The agents did not see each other's outputs; the cross-cutting themes emerged from convergent independent observations.

The audit deliberately did NOT score: marketing copy, brand polish, founder narrative, or "does this matter for child safety" (the answer to that is assumed yes; the question is whether it's *implementable*).

Re-run cadence: re-score after items 1–8 land. Tracking each dimension's progression in `_planning/audit-history.md` (forthcoming).
